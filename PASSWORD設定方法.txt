PASSWORD + ENTER 簡易ロック版

■ 合言葉を変更する場所
js/login.js

この行だけ変更します：

const PASSWORD = "CHANGE-ME";

例：
const PASSWORD = "yakusoku2026";

保存してGitHubへアップロード／Commitすれば変更されます。

■ 仕組み
・index.html を直接開く
・characters/ の個別ページを直接開く
・stories/ の小説ページを直接開く
↓
合言葉をまだ入力していない場合は login.html へ移動します。

正しいPASSWORDを入力すると、そのブラウザに認証済みフラグを保存します。
その後は通常どおりサイトを閲覧できます。

■ 重要
これは「合言葉を知らない一般閲覧者を入口で止める」ための簡易ロックです。
本格的なアクセス制限ではありません。

Publicリポジトリでは、
・GitHub上のソースコード
・stories/kanto/text/*.txt
などを直接探せば閲覧できる可能性があります。

つまり「URLを知っている友人向けの合言葉サイト」には向いていますが、
絶対に外部へ漏らせない原稿の保護には向きません。

■ 今のサイトデザイン
既存の index.html / CHARACTER / STORY / EXTRA の見た目は変更していません。
既存ページには認証チェック用scriptを1行追加しただけです。
